## Overview
A procedural racing track generator for Unity that automatically 
creates unique, driveable racing tracks at runtime or in the editor. 
No two tracks are the same.

## Features
- Procedural track layout generation
- Spline-based smooth track curves
- Automatic road mesh generation
- Configurable track width and barriers
- Runtime and editor-time generation
- Seed-based generation (same seed = same track)
- Playable tracks with proper corner navigation
- Road surface, skirt, and barrier meshes

## How It Works
1. Add the TrackGenerator component to a GameObject
2. Configure your track settings (width, length, style)
3. Click "Generate Track" or call it at runtime
4. Every generation produces a unique driveable layout

## Requirements
- Unity 6.0 or newer
- com.unity.splines package (included)
